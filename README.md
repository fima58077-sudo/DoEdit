# DoEdit

Менеджер IPA в стиле Material You (iOS 12+).

- принимает IPA через «Добавить IPA», «Поделиться -> DoEdit» или папку приложения в «Файлах»
- показывает иконку, имя, bundle id, версию и размер
- передаёт установку в TrollStore или в любое приложение через «Открыть в…»
- 8 акцентных цветов, светлая и тёмная тема

Сам DoEdit без джейлбрейка и без TrollStore ставить чужие IPA не может: это ограничение iOS.

## Сборка
1. Создай репозиторий на GitHub и загрузи все файлы (папку .github сохрани).
2. Actions -> Build DoEdit IPA -> Run workflow (нужен macOS-раннер, там есть Xcode).
3. Скачай артефакт DoEdit-ipa и установи DoEdit.ipa через TrollStore, Filza (джейлбрейк) или Sideloadly.
